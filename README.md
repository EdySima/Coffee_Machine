# Coffee Machine Simulator

A desktop application built with Java Swing that simulates a modern vending coffee machine interface. It features an intuitive graphical user interface (GUI) for customers to customize and purchase drinks, alongside an administrative Service Mode for inventory and resource management.


## Customer Interface

- Beverage Selection: Main dashboard offering a variety of hot drinks (Small Coffee, Large Coffee, Espresso, Cappuccino, Tea, etc.).
- Flexible Payment System: Siulation for both Cash and Card payment methods.
- Customization: Allows users to adjust the sugar level according to their preference before ordering.
- Change Return: Instant refund of any remaining credit after a transaction or cancellation.


## Service Mode

- Dedicated access button to enter Service Mode.

- Allows to monitor and refill machine consumables, including:
    - Coffee beans / ground coffee
    - Water levels
    - Milk reserves
    - Cups and sugar stock


## Prerequisites

To run this application, you need:
    - Java Runtime Environment (JRE) 8.0 or higher installed on your system.

To start the application you need to run Coffee.jre or Coffee_Machine.exe


## Run the application:

- Option A (Windows Executable): Double-click on Coffee_Machine.exe. (A jre folder must be created in the project.)
- Option B (Cross-Platform JAR): Run the following command in your terminal/command prompt:

```bash
java -jar Coffee.jar
```
